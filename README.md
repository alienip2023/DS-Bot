# DS Bot

`ds-bot` 是 DeepSeek Harness（DSH）的团队 Bot 插件。本 fork 的版本是 `0.3.8-fork.61`，功能入口在 [ds-bot/index.js](ds-bot/index.js)。每个 Bot 可以在独立会话中工作，也可以通过群聊和 Bot 间消息协作。主 Bot 负责管理团队。

## 安装

在已安装 DSH 的环境中，用本 fork 的 `.tgz` 安装插件。将 `<tgz>` 替换为归档文件的路径。

```sh
dsh plugin install <tgz>
```

## 本 fork 相对上游的四项改动

1. **校验沙箱**。Codex 引擎必须返回实际生效的沙箱。引擎未返回沙箱，或返回结果与请求不符时，插件会停止该轮。
2. **审批由用户决定**。本地 Agent 发起审批请求时，即使使用完全访问预设，插件也不会自动放行。
3. **重启只重放提交前被拒的一轮**。恢复时只重放明确在提示提交前被拒且没有输出的一轮。提示已提交、已有输出或状态未知的轮次均跳过。
4. **排队消息跨重启保留**。同一个 Bot 的一轮仍在运行时，后续进入队列的用户消息将文字全文写入 `thread-queue.json`，界面预览仍最多显示 120 字。重启后，插件按队列将尚未发送的文字原文重发一次。带图片的消息只还原文字，纯图片消息无法恢复。
