# ds-bot 与 AC（dsh-ai-cluster）的配套版本

主控和每个节点都要装配套的两个插件。ds-bot 读取节点 hello 里的能力（`caps`）和 `acVersion`（AC 0.4.28 起上报）：AC 不够新的节点会在 Bot 列表里被标出「需要升级」（`nodeCompat`），并带上它报告的版本和需要的版本；缺哪项能力，对应功能就退回到节点能做的事，并如实告诉用户，不会悄悄只做一半。
