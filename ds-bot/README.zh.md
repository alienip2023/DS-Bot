# ds-bot

`ds-bot` 是 DeepSeek Harness（DSH）插件，本 fork 的版本是 `0.3.8-fork.63`。插件的 host 入口是仓库内的 `ds-bot/index.js`，由包入口 `plugin.js` 加载。插件在 DSH 会话中运行 Bot，支持主 Bot 管理团队、Bot 间消息和群聊。

## 安装

在已安装 DSH 的环境中，将 `<tgz>` 替换为本 fork 的插件归档路径。

```sh
dsh plugin install <tgz>
```

## 本 fork 相对上游的四项改动

### 沙箱校验

插件向 Codex 引擎请求沙箱后，会校验引擎返回的实际沙箱。引擎未返回沙箱，或其结果与请求不符时，插件会停止该轮。

### 审批不自动放行

本地 Agent 发起的审批请求不会因为使用完全访问预设而自动获准。需要放行的请求由用户确认，只读预设仍可直接拒绝会修改内容的请求。

### 重启只重放提交前被拒的一轮

重启恢复时，插件只重放明确在提示提交前被拒且没有输出的一轮。提示已提交、已有输出或状态未知时，插件跳过该轮的重放。

### 持久化排队的用户消息

同一个 Bot 的一轮仍在运行时，后来进入队列的用户消息会把文字全文保存到 `thread-queue.json`。队列界面仍只显示最多 120 字的预览。

重启后，插件按入队顺序将仍有效、尚未发送的消息原文重发一次。如果该 Bot 还有一轮在运行，恢复的消息会先等待。带图片的消息只还原文字，纯图片消息无法恢复。
